# LAIT THYM SEL

Site vitrine du restaurant **LAIT THYM SEL** à Angers.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Wouter
- Lenis
- React Hook Form
- Zod
- Lucide React

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

## Vérification TypeScript

```bash
npm run typecheck
```

## Build production

```bash
npm run build
```

## Prévisualisation du build

```bash
npm run preview
```

## Variables d'environnement

Copier `.env.example` vers `.env.local` si nécessaire et renseigner les variables requises.
